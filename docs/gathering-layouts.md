# Complete gatherer layouts

Clear other actions clears every unused slot on every non-shared regular and controller bar. There are no reserved utility positions, protected side bars or Sprint exemptions. Only the game's shared-bar setting prevents writes, including during Sprint conversion and backup restore. Cleanup remains an explicit saved option; this update does not turn it on for users who disabled it.

Gatherer layouts are no longer limited to twelve actions. They fill non-shared regular bars and controller pages in order, skipping shared pages. With bars 1–3 and controller pages 1–2 unshared, Miner/Botanist use 26 buttons and Fisher uses 31, plus a planned Sprint when no Sprint exists on a shared bar. If regular capacity is insufficient, setup fails before writing; unavailable controller capacity produces a keyboard-only notice. Level/quest locks still apply. All activations remain manual.

Reviewed against the installed current English Action sheet and the compatible engine's DOL replacements. Official action references: [Miner](https://na.finalfantasyxiv.com/crafting_gathering_guide/miner/), [Botanist](https://na.finalfantasyxiv.com/crafting_gathering_guide/botanist/), [Fisher](https://na.finalfantasyxiv.com/crafting_gathering_guide/fisher/). No game data or personal hotbar snapshots are included in the repository.

Lower-cost gathering chance, yield and Patience tiers are distinct choices, so remain assigned. Gift I and II can stack and both remain assigned. The complete collectable toolkit, crystal buffs, detection, nearest/highest-level search, rare-node toggles and Sneak are available. Fisher additionally retains bait selection, lures, both multi-hook actions, both mooch actions, swimbait, catch control, collectables and separate Rest/Quit controls.

## Validation

The optional GatheringActionCheck tool resolves every packaged PvE action against installed sheets and requires all current gatherer class actions to be either directly assigned or explicitly covered by a reviewed upgrade/replacement. The engine-schema tests verify the named replacement presets for every variant. Runtime simulations cover all variants, shared regular/controller pages, insufficient capacity, cleanup of former reservations, stable refresh and exact backup restoration. In-game acceptance remains separate.

Run `dotnet run --project tools/GatheringActionCheck -- "<game>/sqpack"` to repeat the installed-data check.
