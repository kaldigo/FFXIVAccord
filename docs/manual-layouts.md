# Manual layouts — Accord 0.2.15

These are the assigned keyboard buttons, left to right. Controller pages mirror each row using the fixed mapping in ManualLayoutPack. Sprint and Limit Break stay at bar 3 slots 12 and 11. Empty positions are deliberately cleared within the manual profile and restored from the original snapshot later.

Optional native follow-ups have explicit buttons so the fallback also works with Action Change Settings disabled. Automatic native replacements continue to work. See [behaviour and recovery](manual-fallback.md).
