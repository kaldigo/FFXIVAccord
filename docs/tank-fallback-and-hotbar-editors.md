# Tank fallback and hotbar editor correction

The previous UI migration left the role/job override controller on its old tabbed editor and linked it from both Combat and Hotbars. The correction keeps one destination under Hotbars, with matching PvP overrides, explicit Inherit / On / Off fields, sectioned collection overrides and the assignment studio. Role actions, Personal groups, PvP setup and rotation exclusions also use the shared section/row controls. All edits retain the existing shared layout draft, storage model, inheritance order and Save / Discard behavior.

The override editor retains complete mapping replacement, manual-control visibility, joined damage, split mechanics, role actions, exclusions, every automation permission and every rotation preference. Collection overrides copy inherited values when enabled and return to inheritance when disabled. Assignment editing retains order, priority, destination changes, default restoration and personal-group conversion. PvP setup retains one/two rotation buttons and compact mapping.

Combat → Job preferences → Tanks exposes **Tank AoE ranged fallback**. This is one shared preference for PLD, WAR, DRK and GNB, independent of automatic role mechanics. It defaults on to preserve the existing PLD/WAR behavior and gives DRK/GNB equivalent optional AoE fallback. Off suppresses PLD's ranged Holy Spirit/Shield Lob fallback, WAR's Tomahawk fallback, DRK's Unmend fallback and GNB's Lightning Shot fallback on the simple/advanced AoE rotations. Single-target rotation paths, the Pull selector and PLD's normal magic combo retain their existing behavior. DRK/GNB require a valid battle target, action readiness and range, and yield during weaving. A paired Wrath update is required to disable the feature; older engines report that requirement rather than claiming the setting was applied.

Validation includes compiled production selection snippets, runtime settings persistence/rollback/reload, the complete client job/variant compatibility suite, package tests and offline renders linked to the production editor code. Offline previews substitute game services and do not establish in-game combat acceptance.
